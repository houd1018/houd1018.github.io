Virtual Cinema - VR

VR cinema using Pico Unity SDK

Capstone Project - 2023 spring

Functionality:
1. View any website and video on a virtual cinema
2. Move around and switch seat
3. Immersion: real-time lighting, 3D audio, and theater construction

Tech:
1. PICO Unity Integration SDK
2. 3D WebView plugin for Unity using Android native browser
3. Unity XR Interaction Toolkit
4. Unity Avatar system - auto rigging

Software Platform: Unity3D
Hardware Platform: Pico Neo3
