:::overview
We designed an app that integrates shortcuts to frequently used functions. Since the QR code seniors need to show is not only the health code, the app lets users add multiple shortcuts, such as the health code, location code and itinerary code. These shortcuts cut down tedious steps so the elderly can quickly open the QR code or other functions they want.

Because setting up different shortcuts is complicated for older people, we opened a developer community where helpers can pre-set the functions the elderly use most.

- Developed an Android application with Android Studio and Kotlin
- Used a WebView component and click activity to connect shortcuts to WeChat's and Alipay's built-in URLs
- Built the download and introduction website with WordPress
:::
