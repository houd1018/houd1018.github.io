Siamese network applied on Pok´emon dataset for Few-shot classification

Project for 2022 Spring WKU Student Research Day

Description: This project uses a Siamese network to implement Few-shot learning. A dataset of five different Pok´emon images is used to train the model. When inputting a new category of Pok´emon pictures, the Pok´emon types can be identified with the help of a support set. The model will specify which image in the dataset is closest to the input image.

Few-shot learning: This is a machine learning method where the training dataset contains limited information. In this case, we will use a supported dataset that has only a few data to help classify.

Siamese network: This artificial neural network uses the same weights while working on two different input vectors to compute comparable output vectors.

Framework: PyTorch
Neural Network Architecture: VGG-16
Loss Function: Binary Cross Entropy
Optimizer: Adam with initial Lr =1e-4
Input shape: [105,105,3]
Train ratio: 0.9
Batch size: 32
Dataset size: 1500 images
Epoch: 100

Reference:

Fei-Fei, Fergus, & Perona. One-shot learning of object categories. IEEE Transactions on PAMI, 2006.
Bromley et al. Signature verification using a Siamese time delay neural network. In NIPS. 1994.
Koch, Zemel, & Salakhutdinov. Siamese neural networks for one-shot image recognition. In ICML, 2015.
