EaseGO: An android app that helps seniors show the health code

Course Project for CPS3601 Human-Computer Interaction - 2022 spring

We designed an app that can integrate shortcuts to some functions. Considering that the QR code to be displayed is not only the health code, our app allows users to add multiple shortcuts, such as health code, location code, and itinerary code. These shortcuts can cut down on tedious steps so that the elderly can quickly open the QR code or other functions they want to use.
Considering that the setup of different shortcuts is complicated for older people, we opened up a community of developers. So they can pre-set the functions that are often used for the elderly.

• Developed an Android application using Android Studio and Kotlin
• Implemented WebView component and click activity to connect shortcuts from WeChat and Alipay’s built-in URL
• Built download and introduction website using WordPress
